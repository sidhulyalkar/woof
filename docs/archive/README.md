# Historical Development Archive

This directory preserves point-in-time implementation reports, training notes, readiness checklists and planning documents from earlier Woof / PetPath development phases.

They are retained as project provenance, not as the current source of truth.

## Canonical documentation

Use these documents for the current portfolio-facing system:

- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) for system architecture and scale decisions
- [`../PRODUCT_CASE_STUDY.md`](../PRODUCT_CASE_STUDY.md) for product strategy and UX rationale
- [`../ML_SYSTEM.md`](../ML_SYSTEM.md) for ML evidence levels and promotion gates
- [`../api-spec.md`](../api-spec.md) for the API reference
- [`../data-models.md`](../data-models.md) for the data model overview
- [`../../README.md`](../../README.md) for the project entry point

## Why these files are archived

Earlier reports often use milestone language such as “complete,” “production ready,” or “final.” Those documents accurately reflect the development narrative at the time, but they should not be interpreted as present-day validation of the integrated product.

The current documentation deliberately distinguishes between implemented code, integrated behavior, experimental research and future production requirements.
